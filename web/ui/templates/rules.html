BrainWars: How to Play

What is BrainWars?

BrainWars is a fun quiz game where you test your knowledge to earn points. Play in Single Player mode or compete with others in Multiplayer mode.

Getting Started

  • Single Player: Jump right into a game.
  • Multiplayer:
    • Create a Room: Host and set up the game.
    • Join a Room: Play with others in an existing room.

Creating a Multiplayer Game

As the host, you can customize:

Game Settings:

  • Number of Questions: Up to 10.
  • Time per Question: Set the duration.
  • Quiz Topic: Choose your own or pick a random one.

Adding Bots:

  • Bot Companions: Add computer-controlled players.
  • Bot Behavior: Bots answer at different programmed speeds.

In the Multiplayer Lobby

  • Chat: Talk with other players.
  • Ready Up: Click "Ready" to start.
  • Game Start:
    • Automatically starts when all players are ready.
    • Force Start: The host can start the game even if some players aren't ready.

After the Game

Once the quiz is over:

  • View Results: Check your score.
  • Analyze Answers: See all players' answers (correct and incorrect).
